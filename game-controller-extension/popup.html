NeuroReach

Select the playable area of a supported game. Pointer controls stay in that area; keyboard controls go to the selected game tab.

Use on Poki, Coolmath Games, Playgama, GamePix, CrazyGames, 2048 or Angry Birds Friends.

Chrome shows a debugging notice while connected. Alt+Shift+S stops game input. Close the controller to stop the camera.
