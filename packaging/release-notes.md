Download NeuroReach Companion for your computer. **Python, Node.js and terminal commands are not required.**

| Computer | Download |
| --- | --- |
| Windows 10/11, 64-bit Intel/AMD | `NeuroReach-Windows-Setup.exe` |
| Mac with Apple silicon (M1 or newer), macOS 15+ | `NeuroReach-macOS-Apple-Silicon.dmg` |
| Intel Mac, macOS 15+ | `NeuroReach-macOS-Intel.dmg` |

**Windows:** open the installer, choose Install, then open NeuroReach from the Start menu.

**Mac:** open the disk image, drag NeuroReach to Applications, then open it from Applications. Apple menu → About This Mac shows your chip/processor.

The companion starts automatically and opens the staff workspace. Keep its small window open while playing or supervising. Finish sessions before quitting. Saved records remain on this computer; export a backup before updating.

**First-release approval:** these downloads are not publisher-signed; the Mac app is not Apple-notarized. Windows or macOS may show an unknown-developer warning. Use only this repository's release downloads. On managed devices, ask IT to approve the app. [Apple's app-specific approval instructions](https://support.apple.com/en-us/102445) explain the Mac prompt. Do not disable system-wide security protection. `SHA256SUMS.txt` lists file checksums for IT verification.

Includes the local staff workspace, five games, camera assets, reports, and EEG software runtime. Camera/button play requires no headset. Physical Unicorn EEG still requires the manufacturer's Windows software and hardware; physical headset validation is not part of this release. The experimental app does not diagnose conditions or establish clinical recovery.
